Migração do Portal APH para D1

Importação inicial, protegida por chave secreta.

Não desative o Apps Script ainda.

Esta página importa o catálogo completo uma única vez. A versão pública continua funcionando no Google Drive até você mudar CATALOG_BACKEND para d1 no GitHub.

1. Verificar se o D1 está pronto

Antes de importar, aplique o arquivo SQL migrations/0001_portal_aph.sql no banco portal-aph-db.

Voltar ao portal
Ainda não verificado.

2. Selecionar backup completo do catálogo

Na administração da versão atual, clique em Exportar JSON. Esse backup inclui também cursos e módulos ocultos.

Nenhum arquivo selecionado.

3. Autorizar a importação

A chave de migração deve ser criada em Cloudflare → Worker cursos-aph → Settings → Variables and Secrets, com o nome exato MIGRATION_KEY e tipo Secret. Escolha um valor aleatório com pelo menos 32 caracteres.

Atenção:

O banco D1 terá sua própria senha de administração. Você pode escolher a mesma que utilizava no Apps Script, mas ela precisa ser configurada novamente aqui. Não coloque essa senha no GitHub.

Aguardando arquivo e configuração.

4. Verificar antes de ativar

  1. Confirme se as quantidades de cursos, módulos e vídeos no D1 são iguais às do backup.
  2. Abra /api/d1/status e confirme imported: true.
  3. Somente então, altere "CATALOG_BACKEND": "legacy" para "CATALOG_BACKEND": "d1" no wrangler.jsonc e publique pelo GitHub.
  4. Valide a navegação no Chrome e no painel administrativo. Mantenha o backup original para retorno.
